# Replay Lab golden cases

Each case is a permanent regression test: evidence, the faults to inject,
the arbitration path to run, and the result the replay must produce. They
run in CI through `robot-blackbox lab verify` and `tests/unit/lab/test_cases.py`.
See [docs/REPLAY_LAB.md](../../docs/REPLAY_LAB.md) for what the fields mean.

## Evidence

Both bundles are **SYNTHETIC**: the flight recorder's own GO2 + HELIX traffic
generator (`blackboxrs/flight/synthetic.py`) through the real recorder core
and bundle writer, profile `fixture_profile.yaml`, regenerated byte for byte
by `scripts/generate_replay_lab_evidence.py`. The odometry is a first-order lag
model, not a GO2 measurement. No real robot data is in this directory.

| Evidence | Initial conditions |
|---|---|
| `nominal_motion` | 6.5 s. `/nav/cmd_vel` at 20 Hz commands 0 m/s, then 0.15 m/s from t = 2 s. HELIX hold published at 10 Hz, never asserted. Recorded `/cmd_vel` and ArbiterStatus follow the command. Odometry and lowstate at 20 Hz from the robot host, whose clock runs 1.734 s ahead of the payload. An operator marker at t = 3 s made the recorder write the bundle. |
| `clean_stop` | As `nominal_motion`, but at t = 3.0 s an injected benign HELIX fault is diagnosed, STOP_AND_HOLD is accepted and `/helix/hold` asserts; the recorded arbiter output goes to zero and odometry decays to a stop. `/nav/cmd_vel` keeps asking for 0.15 m/s throughout. |

## Cases

other one fails the case); info findings are listed in each case file.
`twist_mux_legacy` cases pin down the historical failure; the matching
`helix_arbiter` case shows the intended design holding against the same
fault.

Each case file also carries `regression` (the failure class and the document
that records it) and `initial_conditions`.

The failure classes come from HELIX `docs/MOTION_ARBITRATION.md` (twist_mux
4.3.0 measured forwarding NaN, going silent when idle, and teleop at priority
200 above the HELIX stop at 100) and HELIX `docs/GO2_FIELD_NOTES.md`
(CycloneDDS on a missing interface: topics advertised with no data; robot and
payload clocks skewed). Those documents record observations made against the
real twist_mux binary and the real GO2; the cases here reproduce the failure
class on synthetic evidence and are not hardware results.
